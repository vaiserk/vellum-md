# Wikilinks

Três formas de ligar uma nota a outra:

1. **Simples** — aponta para a nota inteira: [[Segundo Cerebro]]
2. **Com apelido** — o texto lido é outro: [[Segundo Cerebro|meu sistema de notas]]
3. **Com âncora** — aponta para uma seção: [[Segundo Cerebro#Princípios]]

O autocompletar abre ao digitar os dois colchetes, e `Ctrl+clique` no editor
abre o destino sem passar pela pré-visualização.

> [!NOTE]
> Uma ligação para nota que ainda não existe fica marcada, como esta:
> [[Nota Futura]]. O clique oferece criá-la.

Quem aponta para esta nota aparece na aba de backlinks — ver [[Notas Atomicas]].
