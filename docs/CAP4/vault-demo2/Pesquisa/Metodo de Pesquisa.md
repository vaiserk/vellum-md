# Método de Pesquisa

Pesquisa aplicada, de natureza exploratória, conduzida em quatro etapas.

```mermaid
graph LR
  A["Revisão bibliográfica"] --> B["Modelagem"]
  B --> C["Implementação"]
  C --> D["Validação"]
  D --> B
```

1. **Revisão** — carga cognitiva, PKM e recuperação por significado
2. **Modelagem** — requisitos e diagramas UML
3. **Implementação** — ciclos curtos, com teste automatizado
4. **Validação** — roteiro de testes e revisão por requisito

O retorno da validação à modelagem é o que caracteriza o ciclo iterativo.

Base conceitual em [[Segundo Cerebro]] e [[Carga Cognitiva]].
