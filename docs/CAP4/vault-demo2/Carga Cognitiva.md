# Teoria da Carga Cognitiva

A memória de trabalho processa poucos elementos ao mesmo tempo. A sobrecarga
informacional ocorre quando o volume de entrada excede essa capacidade.

| Tipo | Origem | Como reduzir |
|---|---|---|
| Intrínseca | Complexidade do conteúdo | Fragmentar em partes |
| Extrínseca | Forma de apresentação | Interface limpa |
| Germânica | Construção de esquemas | Conectar notas |

A projeção é de **221 zettabytes** de dados gerados no mundo em 2026.
